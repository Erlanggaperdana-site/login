1. Flowchart Autentikasi

Alur login, register, dan pengarahan dashboard berdasarkan role.

Keterangan alur

  • Jika session masih aktif, user langsung diarahkan ke dashboard sesuai role.
  • Kredensial salah → kembali ke halaman login dengan pesan error (garis kembali ke kiri).
  • Register dapat diakses dari link di halaman login; hasilnya selalu role customer.
  • Setelah login/register berhasil, session di-regenerate untuk mencegah session fixation.

Penjelasan relasi

  • USER — SESSION (1 : N) — satu user dapat memiliki banyak session aktif (login di beberapa perangkat). sessions.user_id boleh kosong untuk session tamu.
  • USER — PASSWORD_RESET_TOKENS (1 : 1) — satu user memiliki paling banyak satu token reset password aktif, dikaitkan lewat kolom email.
